### Key Concepts

The essay introduces several formal distinctions:

- **Selective projection**: Mⱼ(t) = Πⱼ(S(t)) — participants receive deliberately unequal views
- **Coordination equivalence**: States requiring the same continuation vs. information-theoretic similarity
- **Consequential aliasing**: When projections collapse states that require different actions
- **Production/perception asymmetry**: G_produce ≠ G_perceive
- **Indexed recoverability**: System retention ≠ participant recoverability
- **Minimal coordination messages**: Exporting only action-relevant quotients
